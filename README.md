# ZBack

A simple Minecraft plugin. Allow players back to death location with command.

一个简单的插件，允许玩家用命令返回死亡点。

## Commands

- `/back`
  - teleport sender to last death location
  - permission node `nzd.back`

- `/back info`
  - print sender's last death location information
  - permission node `nzd.back.info`

- `/back info [target: String]`
  - print target player's last death location information
  - permission node `nzd.back.info.others`

OPs can use all the commands.

## 命令

- `/back`
    - 将发送者传送至上次死亡地点
    - 权限节点 `nzd.back`

- `/back info`
    - 打印发送者的上次死亡地点信息
    - 权限节点 `nzd.back.info`

- `/back info [target: String]`
    - 打印目标玩家的上次死亡地点信息
    - 权限节点 `nzd.back.info.others`

OP 可以用所有命令。
